# Aston-Martin_min_web
🚗 Aston Martin Mini Website
A sleek, responsive mini website inspired by the Aston Martin brand — featuring luxury car visuals, F1 branding, and a modern web design aesthetic.
🔗 Live Demo: aston-martin-min-web.vercel.app
📌 About
This project is a front-end mini website built to replicate the look and feel of an Aston Martin brand page. It includes a hero section, car model showcase, F1 banner, and interior highlights — all styled with a premium, dark-themed UI.
